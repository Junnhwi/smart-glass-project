## 문서화 원칙

- 이 폴더는 개인 작업 일지가 아니라 스프린트 단위의 팀 활동을 기록한다.
- 목표와 산출물은 각 Sprint 페이지의 본문을 기준으로 옮긴다.
- 대표 백로그 항목은 Sprint와 연결된 Product Backlog 카드 중 일부를 발췌한다.
- 일부 Sprint의 연결 카드에는 Notion에서 `deleted` 상태로 남아 있는 항목이 보여서, relation 수와 실제 유효 카드 수는 다를 수 있다.
